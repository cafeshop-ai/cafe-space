- one reviewer who is not the author has passed it in the room;
- the author has posted a result message, then marked the task done with `resultSeq` pointing at it.

A runner that is never assigned is not a pass: rerun once, then report.

## Rules that do not change

- **D18.** Any change to a wire shape bumps `PROTOCOL_VERSION`, with fixtures first. Any change to a stored shape is a schema migration that rewrites records explicitly. The update-control channel stays at frozen control generation 2 (`fixtures/control-v2/trace.json`); never edit that file.
- **Truthful outcomes.** `applied`, `dispatched`, `rejected` and `unknown` are never merged. Nothing is retried automatically. An unknown outcome is never shown as done or failed.
- **P10 and §8.** Default autonomy and the short brief stay. The binding scope is routing, not a sandbox, so never claim isolation.
- **Paths and secrets.** Paths reach only local owner-only clients. Proxy, CA and SSH-agent values never leave the daemon: UIs get names, masked values and readiness only (room message 283).
- **Public repository.** No real names, emails, private links, room IDs, local paths or secrets.
- **Tests are not loosened to pass.** Fix the cause, as with the launchd and lock races (`14b0c66`).
