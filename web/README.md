# Café Space web UI

React 19 + TypeScript, built with Vite and tested with Vitest (jsdom). The same build runs inside the Tauri desktop shell (local, through the native IPC proxy, D13) and later as the remote browser client (M2). It talks only to the local daemon, through `DaemonClient`; it never calls the cloud.

## Run

```sh
pnpm install --frozen-lockfile
pnpm test        # on Node 25 or newer: NODE_OPTIONS=--no-webstorage pnpm test
pnpm typecheck   # also checks that generated fixtures are current
pnpm build       # builds index.html only
pnpm dev         # then open /preview.html for the layout preview
```

`preview.html` runs the real `App` against a scripted in-memory daemon (`src/preview/main.tsx`). Use it to check layouts at 375 px and desktop width. Vite builds only `index.html`, so the preview never ships.

## Layout

| Path | What it holds |
|---|---|
| `src/state/DaemonClient.ts` | Connection, handshake, snapshot and event cursor, `call()` for user operations, one open session |
| `src/state/sessionDetail.ts` | Pure reducer that applies ordered events to the open session |
| `src/app/App.tsx` | Routes (`#/sessions`, `#/sessions/<id>`, `#/settings`, …) and page composition |
| `src/app/copy.ts` | All user-facing wording: states, outcomes, error codes, tool-approval marks |
| `src/components/` | One component per screen part (sheet, session view, settings, first run) |
| `src/protocol/generated/` | TypeScript types generated from the Rust protocol crate. Never edit by hand |
| `src/protocol-fixtures.generated.ts` | Shared JSON fixtures, generated by `scripts/generate-protocol-fixtures.mjs` |
| `test/` | Vitest tests; `session-ui.test.tsx` shows the fake-transport pattern |

## Rules

- **The protocol belongs to Rust.** Types and fixtures are generated from `crates/protocol`. A UI need that the protocol cannot express goes to the protocol owner as a request. Fixtures come first, and any shape change follows architecture D18 (version bump, stored-state migration). Never add a request or field only in TypeScript.
- **Truthful outcomes (UX §6.1).** Show `applied`, `dispatched`, `rejected` and `unknown` with the shared `OutcomeMark` and the wording in `copy.ts`. *Sent* never uses a check mark. An unknown outcome is never shown as failed or done, and nothing is retried automatically. Reuse the same client-chosen ID when the user asks again.
- **No silent loss.** Keep drafts when a send is rejected or unknown. Show expired approvals as expired. Mark truncated history.
- **Paths only at this computer.** Project roots come from `get_project_root`, shown only when `local` is true. Shared lists and events never carry paths.
- **Tool approval (D18).** Every agent and session shows its `toolApproval` mark. `unknown` is never presented as safe.
- **Chinese first.** UI text is Chinese and lives in `copy.ts` or the component. An Enter key press during IME composition must never submit.
- **Bounds.** Respect protocol limits in the client: prompt bytes, messages, approvals. Never grow memory with a long session.
- **Accessibility.** Every control is reachable by keyboard and has a 44 px target. Focus rings use the brand color. Honor reduced motion.
- **Public repository.** No real names, emails, private links, room IDs or local paths in code, fixtures or tests. Use the *Alex* persona and synthetic paths.
